# Stage-2 Truncation-K 6-13 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend every active Stage-2 truncation-K action from K8-K13 to K6-K13 without changing the categorical meaning of the existing six actions.

**Architecture:** Add one torch-free `truncation_levels` module as the sole owner of the K domain, its compatibility ordering, parsing, validation, bounds, and baseline lookup. Existing action codecs, cost/reward code, and policy launch paths consume that shared contract; the canonical layerwise policy grows only its five K heads from six to eight categories, while retaining six action slots per Transformer layer. Existing fusion maps remain valid because indices 0-5 keep their meanings, while algorithm-contract hashing rejects old six-head checkpoints before state mutation.

**Tech Stack:** Python 3, `unittest`, NumPy, PyTorch for runtime policy/model tests, existing Stage-2 action/materialization and checkpoint helpers.

```python
"""Authoritative torch-free Stage-2 truncation-K domain."""

from __future__ import annotations

import os
from typing import Mapping, Sequence, Tuple

from cli_parse_utils import parse_int_list_text


DEFAULT_K_LEVELS_LEGACY_COMPAT: Tuple[int, ...] = (
    8, 9, 11, 13, 10, 12, 6, 7,
)
SUPPORTED_K_VALUES = frozenset(range(6, 14))
K_MIN_BITS = min(SUPPORTED_K_VALUES)
K_MAX_BITS = max(SUPPORTED_K_VALUES)


def load_k_levels(environ: Mapping[str, str] | None = None) -> Tuple[int, ...]:
    source = os.environ if environ is None else environ
    raw = str(source.get("BLB_TRUNCATION_K_LEVELS", "") or "").strip()
    if not raw:
        return DEFAULT_K_LEVELS_LEGACY_COMPAT
    try:
        values = tuple(parse_int_list_text(raw))
    except ValueError as exc:
        raise ValueError(
            "BLB_TRUNCATION_K_LEVELS must contain only integers"
        ) from exc
    if not values:
        raise ValueError(
            "BLB_TRUNCATION_K_LEVELS must contain at least one integer"
        )
    if len(set(values)) != len(values):
        raise ValueError(
            f"BLB_TRUNCATION_K_LEVELS contains duplicate values: {values}"
        )
    return values


def validate_exact_k_domain(levels: Sequence[int]) -> Tuple[int, ...]:
    normalized = tuple(int(value) for value in levels)
    if (
        len(normalized) != len(SUPPORTED_K_VALUES)
        or frozenset(normalized) != SUPPORTED_K_VALUES
    ):
        raise ValueError(
            "K_LEVELS must contain each supported K value exactly once: "
            f"{sorted(SUPPORTED_K_VALUES)}, got {normalized}"
        )
    return normalized


def baseline_k_index(
        levels: Sequence[int],
        baseline_k: int = K_MAX_BITS,
        ) -> int:
    normalized = tuple(int(value) for value in levels)
    if not normalized:
        raise ValueError("K levels must be non-empty")
    target = int(baseline_k)
    if target in normalized:
        return normalized.index(target)
    return normalized.index(max(normalized))


K_LEVELS = load_k_levels()
LEVELS_K = len(K_LEVELS)
```
