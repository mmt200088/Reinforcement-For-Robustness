Pareto-only Reward 设置

Reward 仍然是硬优先级：P1 表示 invalid 或精度失败，P2 表示精度通过但稳定性失败，P3 表示精度和稳定性均通过。只有 P3 候选进入 cost 优化和 Pareto archive；cost 不能补偿 P1/P2。

P3 cost 不再使用 typical_bits_drop、typical_fusion_count、typical_k_drop 这类人工归一化权重，也不把 fusion、K、bits 合成一个固定加权目标。P3 的 cost vector 是三维 Pareto 目标：maximize fusion_gain、maximize k_gain、maximize bits_gain。

PPO 需要 scalar reward，因此 P3 内部只把 Pareto 事件转换成 bounded shaping：frontier expansion 给正奖励，frontier member 给小正奖励，被 frontier 支配给小负奖励，重复 action hash 近 0 或轻微负。这个 scalar 是事件信号，不代表人为 cost 权重。
