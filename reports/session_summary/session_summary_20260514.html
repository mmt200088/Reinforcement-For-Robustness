  • 删掉旧的 _build_replan_output_dict、_snapshot_graph_delta_state 等私有辅助（这些功能现在都在 rescale_optimizer.replan_interface 里）。

7. apply_optimizer_output_to_cfg 与 env.step 改造

新增的核心 helper：

def apply_optimizer_output_to_cfg(
    cfg, *,
    output_raw,            # ReplanSession 返回的 dict（含 new_compact_config）
    block_idx,             # 1..5
    graph_key,             # e.g. "block3_exp_n4"
    baseline_skeleton,     # invoker.baselines[graph_key][0]
    cfg_to_t_new_table=None,
    rotation_name_map=None,
) -> List[CfgOverrideEntry]

它会就地改写 cfg，把以下五类信息全部从 optimizer 返回反写回来：

  1. Source SF（skeleton[0]）→ cfg.<*_fresh>.scaling_factor。
  2. Surviving rescale → cfg.<*_result_rescale>.scaling_factor = sf_post（包括 tuple 字段 square_rescales[k]、gelu_*_rescales[k]）。
  3. Fused-away rescale（baseline skeleton 位置在 post-fusion cut_point_sf 里找不到）→ cfg.<*_result_rescale> = None，模型 forward 时这里就不再注入噪声。
  4. Propagation deltas（CTPT_MUL 节点）→ cfg.<*_encode>.scaling_factor，通过新增的反向表 GRAPH_NODE_TO_CFG_ATTR[block_idx]（与 default_block{N}_cfg_to_delta 严格对偶）。
  5. Effective rotations → 先把所有 rotation_after_* 标志清零，再按 rotation_name_map 把 optimizer 实际启用的 rotation 名转成 cfg flag 名置 True。

函数返回 List[CfgOverrideEntry]，每条记录 (cfg_attr, graph_node, source, old_value, new_value)，便于 HTML / 日志展示。

env.step 改造：

原行为新行为
只读 new_compact_config.effective_rotations，调 apply_rotation_flags_to_cfg 设置 rotation 标志位。其它 SF 仍来自 RL 动作。 对每个 opt_outputs[cn]：拿到 graph_key = _strip_layer_suffix(cn)[0]，baseline_skeleton = invoker.baselines[graph_key][0]，调 apply_optimizer_output_to_cfg(...)。改动列表存进 info["optimizer_cfg_overrides"] 便于在线 introspect。
